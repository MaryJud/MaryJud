### 🚀 About Me

I am a Full Stack Software Developer with nearly 4 years of experience in designing and developing enterprise web applications, specializing in document management and process digitization.  
Throughout my career, I have worked across the entire software development lifecycle: from engineering backend logic with Java 21 and Spring Boot, building REST APIs, managing SQL databases, and handling system integrations, to crafting complex, user-centric interfaces.  
My frontend background includes building enterprise applications with a component-based approach using JSF, PrimeFaces 15, XHTML, CSS, JavaScript, and Bootstrap 5. I have extensive experience building dynamic forms, interactive dashboards, reusable components, and integrating frontends with enterprise business workflows via Camunda 8.  
Frontend development and UX/UI design are the primary areas where I am focusing my professional growth. I am currently deepening my expertise in modern frontend frameworks like Angular 17 and React.js, actively applying these skills in production environments.  
I bring a holistic end-to-end perspective to software engineering—combining a solid backend foundation with a keen eye for interface quality, usability, and visual detail.

🔭 &nbsp;I'm currently working on **React Project with Camunda**  
🌱 &nbsp;I'm currently learning **UI-UX Design**
